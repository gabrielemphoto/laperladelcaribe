# La Perla del Caribe &bull; Inversiones Inmobiliarias &amp; Turísticas

Landing page de alta conversión para proyectos y activos de inversión en la **Isla de Margarita, Estado Nueva Esparta, Venezuela**.

Diseñada para inversionistas locales e internacionales interesados en el renacer del sector inmobiliario, la reactivación turística y las ventajas tributarias de la **Zona Económica Especial (ZEE)** y el **Régimen de Puerto Libre**.

---

## 🌟 Características Principales

- **Diseño Luxury & Caribecéntrico**: Paleta inspirada en las aguas turquesas del caribe venezolano, tonos dorados perla y fondo nocturno deep navy.
- **Calculadora Interactiva de ROI**: Simulador en tiempo real con tasas estimadas según el modelo de negocio (renta vacacional, plusvalía de preventa, hotelería boutique).
- **Enfoque ZEE y Puerto Libre**: Sección dedicada a incentivos fiscales, exenciones arancelarias e inversión protegida en divisas.
- **Captación de Leads & WhatsApp**: Formulario de registro conectado dinámicamente con mensaje estructurado directo al WhatsApp comercial.
- **100% Responsive & Accesible**: Optimizado para dispositivos móviles, tablets y monitores de alta resolución.
- **Zero Friction / Dual Run**: Se puede abrir directamente en el navegador con solo hacer doble clic en `index.html` o ejecutar mediante entorno moderno con **Vite**.

## 🚀 Cómo Ejecutar el Proyecto

### Opción 1: Entorno de Desarrollo Rápido con Vite (Recomendada)

1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Iniciar el servidor local con recarga en vivo:
   ```bash
   npm run dev
   ```
3. Abrir la URL local indicada en la consola (usualmente `http://localhost:5173`).

### Opción 2: Sin Instalación previa

Simplemente haz doble clic en el archivo `index.html` o usa cualquier extensión de Live Server en tu editor.
